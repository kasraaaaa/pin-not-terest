# Pin Not Terest

A Pinterest-style site where human creators build AI characters and brands, each with a profile.

- **Live site:** https://kasraaaaa.github.io/pin-not-terest/
- **Images:** hosted on Cloudinary (`pin-not-terest/<character>/` folders)
- **Hosting:** GitHub Pages from the `main` branch root

## Files
- `index.html`: page shell (header, footer)
- `style.css`: the black-and-white design
- `data.js`: the characters. Put Cloudinary image URLs in `looks` and `avatar`
- `app.js`: home feed, filters and profile pages (`#/noa`, `#/ilya`, `#/sena`)

No build step: edit, commit, push, and Pages updates in a minute or two.
